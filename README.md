# The Drop

An interactive museum exhibit about Galileo, gravity, and the legend of the Leaning Tower of Pisa.

**What if the most famous science story isn't true — but the truth is even better?**

Six galleries guide you from myth to method: the tower legend, the inclined plane experiment, the thought experiment that broke Aristotle, and the vacuum where everything falls together.
