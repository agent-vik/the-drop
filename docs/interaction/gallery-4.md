# 馆 4：斜面 ⭐ 全馆高潮 — 交互设计

*通用原则见 [principles.md](./principles.md)；历史事实见 [factsheet.md](../factsheet.md)。*

**一句话**：自由落体太快了。他把它放平。

**入口处**出现全馆唯一一次完整主题句。

**装置**：中央 7m 木梁（复刻），约 5° 倾斜，槽贴羊皮纸，青铜球在顶端。三个标记点：1/4、1/2、全长。

馆 4 分为**入口区**与**主区**两部分，同馆无缝衔接。

---

## 入口区（塔的回响）✅ 已定稿

**叙事作用**：制造「测不准」的挫败感，引出斜面「把时间稀释」的精妙。入口区演的是「人测快物体 → 噪声大」，与主区「伽利略测慢动作 → 比例干净」形成对比。

**操作流程**：
1. 观众释放球（复用馆 1 的动作——同一个装置，意义从「奇迹」翻转为「难题」）
2. 眼睛盯落地的瞬间，手掐秒表
3. 读数入计时板，装置自动复位，可继续投
4. 不限次数——多次投的目的是看到离散，不是看到收敛（收敛是主区的戏，不抢）

**自恢复机制（✅ 已定稿）**：复位是幕后工作，不是内容——

```
① 落地 + 秒表停 → 读数入计时板
② 球在地上短暂停留 → 原地渐隐消失（不升回——复位不该抢读数焦点）
③ 球和凹槽再次在塔顶出现，秒表淡回待命
④ 回到静候态 → 可继续投
```

- 无次数限制：3 次测完观众还能继续投，装置不会进入停摆状态，永远自洽、永远可恢复
- **计时板容量 5 格，先进先出**：新读数把最旧的顶掉；离散的结论不需要满 3 个才成立，前两个差异已经可见，滚动窗口只保留最近的现场
- 超时未记录的一投（球落地但没掐）同样走完复位，装置照常归位

**显示规则：显示观众自己掐出的原始时间（保留一位小数）**，而不是只显示「三次差了多少」。这样所有边界情况都自我解释，观众能把失败归因给自己的操作，而不是归因给系统：

| 情况 | 显示 | 观众的理解 |
|------|------|-----------|
| 掐太晚（8.7s） | 原样显示 8.7s | 「我按晚了」 |
| 掐太早（0.4s） | 原样显示 0.4s | 「球还没落地我就按了」 |
| 迟迟不按 | 超时提示「本次未记录」 | 知道没成功，不算一次 |
| 按了多次 | 取第一次 | 无歧义 |

两个配套规则：
- 允许重来本次：觉得按砸了可以重掐，不竞技、重来无代价，观众心态放松不尴尬
- 首次使用给一句操作提示：「盯住落地点，球落地瞬间按秒表」

不破坏「不显示真实值」的决定：观众看到的是自己的原始读数，不是正确答案。掐晚成 8.7s 也能原样上板，归因给「我手慢了」而非「系统说我不对」——归因给自己，挫败感才指向「测量这件事本身太难」。

**屏幕时长**：与馆 1 同一座塔，同一下落时长（约 1.45 秒，画幅地球 g）。factsheet 里 50 m ≈ 3.2 秒仍是真塔的数，不写进秒表、不当成「正确答案」提示。

**交互规则**：
- 不显示真实值（不告诉观众「应该是多少秒」）：显示了反而让观众想「多掐几次取平均」，削弱斜面必要性；悬念感更强
- 不做竞技化：不给「掐得准」的评分或奖励，离散本身就是焦点
- 误差来源的真实性：不伪造误差，50m 落体约 3.2 秒，人类视觉反应延迟约 0.2 秒且每次不同，真实的人体反应就足以制造 ±0.3~0.5 秒离散

**球数区分（✅ 已定稿）**：

| | 馆 1 | 馆 4 入口区 |
|---|---|---|
| 球数 | **两球**（一炮弹一火枪弹） | **单球** |
| 看什么 | 它们**一起**落地 | 落地花了**多久** |
| 问题 | 重量决定速度吗？ | 你测得准吗？ |

入口区主题是计时，两球会分散注意力；塔还是那座塔，但实验目的变了——观众第二次见到它时，看问题的角度变了，这是「换一副透镜」的又一次预演。放球状态机为馆 1 与入口区共用，球数按上表区分。

**放球手势与状态机（✅ 已定稿）**：

```
静候 → 握住（承诺）→ 松手（落下）→ 测量/复位 → 静候
```

- **静候**：球安放在塔顶木质凹槽里（馆 1 两球，入口区单球）；秒表淡出（低存在感）；球有轻微「可拿」暗示（悬停时微微上浮/高光，安静不催促）
- **握住**：按下瞬间球**微微抬起**（握住的即时视觉反馈）；同时坠落引导线浮现，凹槽**微微缩小并渐隐消失**；秒表苏醒显示 0.0 待命；提示「松手，释放」。触摸区：馆 1 包住两球一整块（不是两个独立目标——传说中两球必须同时释放）；入口区单球
- **松开前的停留**：不超时催促，博物馆不催观众；按住即无回头路（见「无放回分支」）
- **松手**：球落下（馆 1 两球同时）；入口区秒表自动开始计时（机器发起、人来反应，隔离出停止端的人体误差）
- **复位**：落地后球原地渐隐 → 球和凹槽在塔顶重现，回到静候（幕后动作，细节见「自恢复机制」）

**史实考证（维维亚尼记载的空白）**：维维亚尼原文只记载两球重量悬殊、**同时释放**、当众进行；释放机制、持握方式、球的位置在文献中**全部空白**。因此凹槽设计填补的是文献空缺，与记载无冲突；且凹槽恰好保证传说唯一被强调的操作要求——「同时释放」（一个凹槽同时托住两球，一次松手就是同时）。详见 `docs/factsheet.md` 附录 G。

具体交互规则：

- **球不跟随鼠标，原地释放**：落点由塔的物理决定，不存在「选位置」自由度；拖离塔身会破坏「从塔上落下」的虚构
- **坠落引导线**：握住瞬间出现从球到地面的虚线 + 落点标记，直接回答「释放后会发生什么」「在哪释放」；观众若尝试拖动，球不动本身就是反馈
- **指针**：悬停球上 → grab 手型；按住不放 → grabbing 手型
- **凹槽退隐**：握住时凹槽微微缩小并渐隐消失（传达「已腾空」而非「往这里放」）；球落地渐隐后，凹槽与球一同在塔顶重现
- **无放回分支**：握住即承诺，没有回头路——反正也不是破坏性操作，误触的一次无计时落球是无害空操作，不需要「后悔退路」

**点破与过渡**：措辞待打磨；走向主区的引导语已定：「于是他做了另一件事——把问题放平。」（✅）

**触发时机（✅ 已定稿）**：计时板上累计 **3 个有效读数**时触发，点破文字轻轻浮现；浮现后不阻断投球，装置照常可用（可继续投，无次数限制）；走向主区的动线始终敞开。

## 主区（斜面）✅ 已定稿

### 已定稿：测量机制

**模式：收敛式**（与入口区的「离散」对照）。真实计时：掐停时机早一点/晚一点，水量就少一点/多一点。反复测同一个点有意义——测量向真值收敛，「误差被重复吞掉」由观众亲眼兑现。

**真实物理参数（不做任何降难度设计）**：装置按 factsheet 附录 F 的记载参数——7m 木梁、一端抬高 1 腕尺（倾角 4.8°）、青铜球滚动，滚动加速度 ≈ 0.58 m/s²：

| 标记点 | 球到达用时 | 球此刻速度 |
|--------|-----------|-----------|
| ¼（1.75m） | 2.45 秒 | 1.4 m/s |
| ½（3.5m） | 3.46 秒 | 2.0 m/s |
| 全长（7m） | 4.90 秒 | 2.9 m/s（慢跑速度） |

与自由落体对比：50m 落体 3.2 秒但视觉无法追随；斜面上球滚完全程 4.9 秒，目光从容。全长点确实比 ¼ 点难约一倍，但那是「容易」与「更容易」的差别——难度曲线天然合理，不设宽容窗口。人的反应误差 ~0.2 秒，在 4.9 秒测量里仅 ~4% 时间误差。

**全长时机 = 梁尖视觉锚点（史实原样）**：《两门新科学》第三天原文——槽上预标 ¼、½、3/4、全长四个位置，球到标记位置的瞬间拇指封孔。全长就是槽的尽头，和其他标记一样靠眼睛判断，无篮、无响、无机关。梁尖本身是天然锚点。

**掐停手势：点水钟出水口**（修正早期「按容器」提议）。出水口是观众在练习模式认识的水的控制点，手势落在学过的物件上；与释放联动——抽挡板瞬间水自动开始流（机器发起），观众唯一的计时动作是点出水口停水，与入口区秒表同构（自动开始、人来停，隔离停止端误差）。练习模式教的就是这个：抽挡板→球和水一起开始、点出水口→水停。

**判定**：唯一依据是**掐停那一瞬间球在哪**：
- 落在某标记窗口内 → 该点的有效测量
- 停在两线之间 / 未到 ¼ → 无效，装置平静提示，复位重来
- 球已过全长水才停 → 无效（无需特殊结局，画面结局都一样）

**失败路径（不用失败语言，用「这次测量无效」）**：科学家本来就丢弃坏数据（伽利略原文「重复测量直到确认可靠」），这个处理暗合主题但不点破。装置从不指责，只是平静归位：
- 掐早了：水停住，显示这一小汪水，提示「球还没到标记线」，复位
- 两线之间：不算任何点，位置自己说话（过了 ¼、没到 ½）
- 太晚：球滚出梁尖坠落（真实物理延伸，约 0.5 秒）→ 落进梁端小木盘停住 → 停留约 2 秒让观众反应过来「它掉下去了，我没赶上」→ 球落盘同一刻水自动停 → 复位。木盘是设计补充（史实无记载，与馆 1 凹槽同类——历史留白处合理填补），给坠落一个明确的收束。

**天平简化**：水钟下的盛水容器直接放在天平上——水停、天平转向平衡位置，称重不再是额外装置，是水钟的自然延伸。

**测量表（手边桌面）与大屏（工坊墙）：空间上两个，数据上一个**。测量表 = 任务记录（三格：测没测、当前值、×N）；大屏 = 证据墙（历史散点 + 最终曲线）。同一数据源两种呈现：进行中的账本 vs 沉淀的证据。

**均值呈现（观众怎么知道是均值）**：大屏上每次测量留一个**浅色小点**（历史痕迹），进入测量表和曲线的值是**更亮、稳定的点**；反复测，浅色点聚拢到亮点周围——收敛是用眼睛看到的。测量表数值旁标 **×N**（测了几次），`2.4` → `2.4 ×3`。亮点 + 聚拢浅色点 + ×N 三者一起，「均值」自明。

**大屏在结果出来前不展示**：真实实验不会记一个数字画一个点，而是攒满数据再整理成图。大屏藏起 → 反复测的反馈全由测量表承担；散点聚拢从实时小反馈升级为终幕大揭示。且装置屏与结果屏**时间上先后、空间上复用同一块屏**——「细长斜面 + 水钟 + 天平 + 大屏」永不同屏，空间矛盾天然消解（对移动端竖屏是决定性松绑）。

**完成时刻交给观众**：三点各≥1 次有效后，测量表上出现一个 UI 按钮（如「数据已齐 · 画出曲线」）；观众可继续重复测任何点；觉得「够了、稳了」，点按钮 → 大屏浮现（半透明覆盖装置）。设计意图与史实对应：原文「Having performed this operation and having assured ourselves of its reliability…」——自己确认可靠才算完成。按钮出现即收工边界：点击出结果后不能继续测，避免「出了结果还在改数据」的状态混乱。测量表是 UI 层扁平物件（非拟物），完成按钮就放在它上面——「手势模仿装置」原则只管装置操作动作，不蔓延到 UI 层。

### 已定稿：操作流（实验阶段）

```
0. 练习模式（无压力沙盒）：球随便放、水钟随便开关，不记录；
   教的就是正式交互：抽挡板→球和水一起开始、点出水口→水停；
   隐藏收益：第一次感受「球滚得好慢」，时间被稀释先被身体感受
1. 点「开始正式测量」→ 测量表出现（三格全空）+ 首次引导句出现一次后消失
2. 心里选定本次瞄准的标记线（顺序自由，无需点击选择）
3. 抽挡板 → 球滚、水自动开始流
4. 目光追球，球到标记线瞬间点出水口 → 水停；球继续滚（物理）
5. 判定（见上）：有效 → 天平转向平衡、水量入测量表（首测填值；再测更新均值 + ×N）；无效 → 平静提示、复位
6. 自动复位（幕间，不抢戏）：球回顶端、水钟重灌、天平归零
7. 回到第 2 步，任意重复、任意顺序（大屏不可见，测量表更新均值与 ×N）
8. 三点各≥1次后测量表出现完成按钮 → 观众点按钮 → 大屏浮现（半透明覆盖装置）
   → 所有历史散点一次性显现、聚拢 → 三点均值亮点 → 规律文字 → d∝t² 曲线画出
9. 出口：屏幕下方居中扁平按钮（见下）
```

**大屏为半透明背景**：可视化浮现时不完全遮挡装置——背后的装置隐约可见，但已隔着「一层纱」，观众看得见、不再可操作。不设任何返回/重操作入口：这一段已经讲完，若真想重新做实验，走出口走廊的「从头开始」——整个博物馆的重启逻辑只有一个，不出现第二个旁门。

**释放手势（✅ 已定稿）**：单击挡板 → 球滚出（点球作为兜底也能触发）。单击而非拖拽：挡板是测量流程的第一个动作，不该有操作压力。与塔的「按住→松手」形成对比：塔是「交出去」（交给重力），斜面是「放出去」（受控起步，从容不迫）。

### 已定稿：空间排布

**对角线构图**：7m 木梁从画面**左上（远端）斜向右下（近端）**。一条线同时承担三件事：球的滚动路径、视线的引导方向、透视上把长梁压进一屏（远小近大，天然传达长度）。

**各元素位置**：

| 元素 | 位置 | 理由 |
|------|------|------|
| 木梁（含 ¼/½/全长标记、挡板） | 左上 → 右下对角线 | 路径即构图 |

**移动端**：对角线排布下移动端竖屏也摆得下；装置屏与结果屏本就分离，细长斜面只需在本屏内对角线放置，空间矛盾已消解。具体比例待实现时微调。

### 已定稿：首次正式测量引导

**给一句，只给一次，练习模式里不出现。**

缺的不是手势，是目标。练习已教「抽挡板、点出水口」；入口区刚把人训练成「盯落地点、等它到头」。正式测量要把目标从尽头拧到线上——盯**一条**标记线，到线就停。不说破，第一次正式操作会把塔的肌肉记忆搬过来：等到梁尖，全长那格被填上，另外两格不知道为什么是空的。那不是「测量很难」，是「这东西怎么用我不懂」（原则 5）。

失败提示救不了：掐早才出现「球还没到标记线」；等到头是有效的全长测量，系统不说话。测量表三格会事后暗示还缺两点，但不能当场告诉人瞄准什么。

与入口区同句式，只换目标：

> 盯住一条标记线，球到线瞬间点出水口

「一条」是这句里唯一在干活的词：本次只打一个点，顺序自选。不说三个点、不说掐准、不说无效——三格空表自己说「要填满」；掐早掐晚走已定稿的失败路径。

**时机**：点「开始正式测量」、测量表浮现的那一下，轻轻给这句，然后消失；后面每一投都不再提。练习保持无压力沙盒，瞄准不是练习的课题。不把门禁做在练习上（不强迫先玩够才能进正式）。

**明确不做**：不写成按钮长文案；不做成可跳过教程；不在失败一次后再补第二句教程。

### 已定稿：出口动线（主区 → 馆 5）

**一个扁平按钮，屏幕下方居中，仅此而已**。观众在结果屏上看完曲线与规律文字，视线自上而下落到下方，那里是唯一的、符合常规预期的前进按钮。文案不写抽象的「下一馆」，接着叙事写——「去看看它在另一个天体上」。
