# 馆 1：传说 — 交互设计

*通用原则见 [principles.md](./principles.md)。本馆交互 = 塔装置状态机的纯净版，完整规格见 [gallery-4.md](./gallery-4.md)（状态机、手势、引导线、指针语义）。*

**一句话**：这是你听过的故事。

**交互状态**：框架已定（继承自馆 4 讨论中形成的约束），细节待馆 1 正式讨论时补全。

## 已确定的约束

- **两球**（一炮弹一火枪弹），触摸区包住两球一整块——传说中两球必须同时释放，触摸区不拆成两个独立目标
- **握住 → 松手**手势：与馆 4 入口区完全一致，观众第二次见到塔时肌肉记忆完整复现（认出感 = 参与感）
- **无秒表、无读数、无计时板**：松手后唯一呈现的事实是「两球同时落地」
- 不埋任何伏笔——先让观众信

## 重玩机制（✅ 已定稿）

- 主流程是**单次演示**：松手 → 两球同时落地 → 球落地渐隐 → 塔顶空留凹槽，**不自动复活球**
- 重玩通过一个**弱化的重试入口**开启：落点附近一个安静的小按钮（低存在感、不提示、不催促，见 principles.md 原则 7），点击后球与凹槽在塔顶重现
- 弱入口的理由：馆 1 的重点是「同时落地」这个事实的消化，重玩是可选彩蛋而非内容
