## 设计参考（内部分析）

*从同类互动展品项目中反推的设计语言总结，仅作思路参考，不照搬。*

- 深夜展厅式底色（近纯黑微蓝），卡片稍亮
- 单一贵金属主色（含亮/暗两档），文字暖白多档层次
- 字体三件套：衬线（标题）+ 无衬线（正文）+ 等宽（数据/标签）
- 全页固定主题纹样背景（主题相关的淡色细线几何纹）——纹样进背景
- 细边框、小圆角、窄栏阅读
- 逻辑：「深夜展厅 + 单一贵金属 + 主题纹样进背景」，全 UI 无渐变

## 设计决策记录

### 决策 1：逐馆换景（路线 C）

五个馆各自独立的房间氛围，共享系统层。题材气质决定风格方向：16–17 世纪意大利物理实验，有石头、羊皮纸、青铜、月面。

### 决策 2：贯穿 vs 特有的架构划分

**贯穿始终（系统层 = 博物馆的 DNA）**：
1. 字体三件套（衬线/无衬线/等宽的分工 + 具体字体，**字体贯穿不随馆变**——字体是博物馆的嗓音，换馆换字体等于换讲解员）
2. 排版系统（字号阶梯、行高、栏宽、馆号→标题→一句话→内容的层级规则）
3. UI 语汇（按钮、提示、语言切换、进度指示器；交互状态语言；指针语义）
4. 主题色及其角色体系（见决策 3）
5. 动效语言（渐隐/浮现节奏、缓动曲线、复位动画、馆间过渡规范）
6. 叙事声音的呈现方式（单句成屏、点破句淡入、不强调不催促）
7. UI 系统元素的稳定性：**馆间过渡时导航/进度/语言切换留在原地不动，只有氛围层渐变切换**——观众换房间时有一个不动的锚点

**各馆特有（主题层 = 每个房间的氛围）**：
1. 材质纹理与背景纹样（按决策 5 分层）
2. 光的性格（若做，必须是真实光照层——径向聚光、暗角、方向性明暗，CSS 层叠实现；**仅靠底色色值偏移的差异观众感受不到，禁止用色值差异冒充光**）
3. 背景明度（在弧线范围内，见决策 4）

### 决策 3：主题色 = 琥珀铜金（扁平，无金属质感）

- 出处：五个馆的材质里唯一贯穿始终的物体是**下落的球**，球的金属色是全馆唯一"场场都在"的颜色
- **色相 ≠ 质感**：主题色是「从金属那里借来的颜色」，不是「金属的皮肤」。UI 强调色是纯扁平单色值（如 `#d4a574` 一族，偏铜不偏金），无渐变、无光泽、无纹理
- 青铜质感只出现在**展品绘制层**（青铜球作为展品的图形渲染），与 UI 配色系统无关；抛光青铜偏暖铜金，青绿锈色只在刻意做旧时用
- 兼容性已验证：石+金属色 ✅、旧纸+金属色 ✅、木/羊皮纸/青铜 ✅、月面灰黑+金属色 ✅（馆 5 中暖色退到 UI 角落，眼前只剩灰黑，反而制造叙事反差）

### 决策 4：全深底「夜间博物馆」+ 明暗弧线

- 所有馆深底亮字，不做浅色馆——馆 1 的「白昼感」靠最亮的深底 + 光性表达，不靠浅色底（浅色底会让馆 1 显得不属于这座博物馆，且共用主题色在浅底上失真）
- 明暗弧线（草案色值）：

| 馆 | 底色（草案） | 光的性格 | 画面 |
|----|------------|---------|------|
| 馆 1 传说 | `#211a12` 暖石灰褐 | 漫射天光 | 日光洒进塔内石壁 |
| 馆 2 裂缝 | `#14100a` 尘褐 | 一盏孤灯 | 深夜档案室，一束灯压在旧纸上 |
| 馆 3 推理 | `#131210` 中性暗 | 无来处的匀光 | 没有窗的房间，只有推理链 |
| 馆 4 斜面 | `#1f160d` 木工坊褐 | 一扇侧窗光 | 工坊午后，窗光切过 7 米的桌子 |
| 馆 5 真空 | `#050508` 近纯黑 | 无环境光 | 月面，黑到只剩影像和你 |

- 弧线形状：馆 1 最亮最暖 → 馆 2/3 暗下去 → **馆 4 回暖**（高潮是亲密的桌面，不是宏大）→ 馆 5 骤降纯黑（前面攒的暖抽走 = 月面震撼）

### 决策 5：材质按「具象程度」分层

| 层 | 范围 | 手法 |
|----|------|------|
| 系统基底 | 全馆 | 纯色深底 + 微妙几何纹理 |
| 图片背景层 | **仅馆 1（塔）和馆 5（月面）** | 真实图片，必须压暗/降饱和处理，保证装置与文字可读 |
| 装置层 | 馆 2/3/4 的区分主力 | 不靠背景靠展品：证据卡片布局、推理链呈现、7 米木桌 |

- 分层依据：馆 1、5 有具象锚点（观众脑中本有画面），图片兑现想象且收益大（馆 5 的月面黑是照片级震撼，纯色做不出）；馆 3 是抽象空间没有合适照片；馆 2/4 勉强可找但五馆图片风格统一很难
- 图片处理的代价与约束：文字可读性压暗、五馆图片风格统一、版权来源、加载体积、移动端表现——实现前逐一解决
